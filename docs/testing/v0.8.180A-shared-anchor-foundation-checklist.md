# v0.8.180A — Shared Anchor Foundation Checklist

Use this checklist after applying the v0.8.180A package.

## Automated validation

- [ ] `dotnet build OpenCad2D.sln`
- [ ] `dotnet test OpenCad2D.sln --no-build`
- [ ] Confirm `AnchorPointServiceTests` are present and passing.

## Code review validation

- [ ] `AnchorPoint` contains exactly the nine canonical values from `docs/specs/shared-anchor-system.md`.
- [ ] `AnchorPointService.Descriptors` is ordered visually from top-left to bottom-right.
- [ ] `Top*` anchors resolve to `BoundingBox2D.MaxY`, not screen top.
- [ ] `Bottom*` anchors resolve to `BoundingBox2D.MinY`.
- [ ] Numeric shortcuts follow keypad order: `7/8/9`, `4/5/6`, `1/2/3`.
- [ ] Invalid string parsing recovers to a caller-provided default.
- [ ] No existing entity persistence has been changed by this slice.
- [ ] No visible HUD, Property Panel or insertion behavior has changed yet.

## Regression validation

- [ ] Existing block insertion still works and still uses the block creation base point.
- [ ] Existing Library insertion still works and still uses the item origin/block base point.
- [ ] Existing stair insertion still works.
- [ ] Save/reopen of existing drawings is unchanged.
- [ ] SVG/PDF/DXF export of existing drawings is unchanged.

## Closeout decision

Mark v0.8.180A as accepted only if the automated tests pass and no existing insertion workflow changed unexpectedly. If failures appear, classify them as either implementation defects in the shared anchor service or unrelated regressions introduced by previous slices.
