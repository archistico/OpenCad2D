# v0.8.180F — Door/window property editing and defaults checklist

Run after applying the v0.8.180F patch.

## Automated checks

```bash
dotnet build OpenCad2D.sln
dotnet test OpenCad2D.sln --no-build
```

## Manual smoke

1. Insert a door with the default settings.
2. Select it and edit width, wall thickness, opening angle, swing direction, anchor and wall mask from the Property Panel.
3. Confirm each edit updates the drawing immediately, keeps the entity selected and supports undo/redo.
4. Try invalid door values: zero width, zero wall thickness and opening angle above 180 degrees. The entity must remain unchanged.
5. Start `DOOR`, choose `W`, enter a new width and insert a door. The inserted entity and preview must use the new width.
6. Start `DOOR`, choose `T`, enter a new wall thickness and insert a door.
7. Start `DOOR`, choose `O`, enter a new opening angle and insert a door.
8. Insert a window with the default settings.
9. Select it and edit width, wall thickness, frame offset, anchor and wall mask from the Property Panel.
10. Confirm each edit updates the drawing immediately, keeps the entity selected and supports undo/redo.
11. Try invalid window values: zero width, zero wall thickness and a frame offset greater than half the wall thickness. The entity must remain unchanged.
12. Start `WINDOW`, choose `W`, `T` and `O` in separate runs and verify the next inserted window uses the updated per-command defaults.
13. Save, reopen and verify edited door/window parameters are preserved.
14. Export SVG/PDF/DXF/PNG and verify the edited geometry and wall masks remain visually coherent.

## Regression checks

- Block insertion still uses the block base point selected during block creation.
- Static Library insertion still uses the item origin/base point and does not use the 9-point anchor selector.
- The HUD anchor selector still affects doors/windows only.
