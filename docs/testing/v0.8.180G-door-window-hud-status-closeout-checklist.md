# v0.8.180G — Door/window HUD status closeout checklist

Run after applying the v0.8.180G patch.

## Automated checks

```bash
dotnet build OpenCad2D.sln
dotnet test OpenCad2D.sln --no-build
```

## Manual smoke

1. Start `DOOR` and verify the HUD prompt shows width, wall thickness, opening angle, swing, anchor and wall-mask state.
2. Press `R` and verify the door prompt reports `S=Right`.
3. Use the HUD anchor selector or numeric shortcut and verify the prompt reports the new anchor display name.
4. Press `M` and verify the prompt reports `M=Off`; press `M` again and verify it returns to `M=On`.
5. Insert the door and verify the inserted entity matches the visible prompt state.
6. Start `WINDOW` and verify the HUD prompt shows width, wall thickness, frame offset, anchor and wall-mask state.
7. Use the HUD anchor selector or numeric shortcut and verify the prompt reports the new anchor display name.
8. Press `M` and verify the prompt reports `M=Off`; insert the window and verify the inserted entity has no wall mask.

## Regression checks

- `DOOR` numeric sub-prompts for `W`, `T` and `O` still work.
- `WINDOW` numeric sub-prompts for `W`, `T` and `O` still work.
- Block insertion still uses the block base point chosen at creation.
- Static Library insertion still uses the item origin/base point.
- The HUD anchor selector still affects doors/windows only.
