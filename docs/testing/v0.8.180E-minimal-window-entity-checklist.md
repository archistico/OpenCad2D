# v0.8.180E — Minimal WindowEntity checklist

Run the normal automated verification first:

```bash
dotnet build OpenCad2D.sln
dotnet test OpenCad2D.sln --no-build
```

Manual smoke checks:

1. Start the Window tool from the toolbar and from the command line with `WINDOW`, `FINESTRA` and `WN`.
2. Move the pointer before clicking and verify that a preview window follows the cursor.
3. Insert a window and verify that undo removes the whole entity in one step and redo restores it.
4. Use the HUD anchor selector or numeric shortcuts 1-9 while the Window tool is active. Verify that the inserted window uses the chosen anchor.
5. Press `M` before insertion and verify that the next window is inserted without the wall-opening mask.
6. Select a window and verify that the Property Panel shows insertion point, anchor, width, wall thickness, frame offset and wall mask state.
7. Toggle `Wall mask` from the Property Panel and verify undo/redo.
8. Save, reopen and verify that masked/unmasked windows preserve their state.
9. Export SVG, PDF and DXF and verify that masked windows include a white wipeout-style opening before visible linework, while unmasked windows do not.
10. Recheck Insert Block and Library item insertion: their insertion point must still be the block/item base point, not the 9-point anchor selector.
