# v0.8.162 compatibility and manual smoke checklist

Use this checklist after applying the v0.8.161 Library content pack. The goal is not exhaustive QA; it is a focused compatibility pass before opening another large feature family.

Record the date, commit/tag, Windows version, .NET SDK/runtime and external viewers used for DXF/PDF/SVG checks.
