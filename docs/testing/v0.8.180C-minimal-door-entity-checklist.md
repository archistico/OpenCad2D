# Manual checklist — v0.8.180C Minimal DoorEntity

Run after applying the v0.8.180C package.

## Automated checks

```bash
dotnet build OpenCad2D.sln
dotnet test OpenCad2D.sln --no-build
```

Expected result: build succeeds and the full test suite passes.

## Door command smoke test

1. Start OpenCad2D.
2. Run `DOOR` from the command line.
3. Move the mouse over the canvas and verify that a door preview is shown.
4. Click a point and verify that a single parametric door is inserted.
5. Undo and redo; the door should be removed/restored as one operation.
6. Run `PORTA` and verify it activates the same tool.
7. Run `DR` and verify it activates the same tool.

## Swing direction

1. Run `DOOR`.
2. Enter `R` or `Right`.
3. Insert a door and verify the swing is drawn on the opposite side from the default left-swing door.
4. Run `DOOR` again, enter `L` or `Left`, and verify the default side is restored.

## Anchor selector

1. Activate `DOOR`.
2. Verify the HUD shows the 3x3 anchor selector.
3. Press/use shortcut `1` and insert a door.
4. Select the door and verify it stores `BottomLeft` as anchor in the property panel details.
5. Activate a non-door tool, such as `LINE`, and verify the anchor selector is no longer shown.
6. Verify block and Library insertion still use their own base point and do not use the 3x3 anchor selector.

## Save/reopen

1. Insert at least two doors with different swing directions and anchors.
2. Save the drawing.
3. Reopen the drawing.
4. Verify the doors keep insertion point, width, wall thickness, opening angle, swing direction and anchor.

## Export smoke test

Create a small drawing containing a line, a block, a Library item, a stair and a door. Export to:

- SVG;
- PDF;
- DXF;
- PNG if available from the current UI flow.

Verify the door appears as ordinary visible linework in vector exports.

## Known limitations to confirm

- Door wall masking was not part of v0.8.180C; it is covered by `docs/testing/v0.8.180D-door-wall-mask-foundation-checklist.md`.
- Door parameters are visible but not fully editable from the Property Panel in this slice.
- Width, wall thickness and opening angle are fixed defaults during command insertion.
- Windows are not implemented yet.
