# Symbols

Symbols are reserved for parametric objects generated by OpenCad2D. This is an important distinction in the project: static reusable drawings belong to the Library, while Symbols are objects that the application creates from parameters.

The planned parametric symbols are doors, windows and stairs. These objects need parameters because their geometry depends on user choices such as width, height, opening direction, number of steps or representation type.

A chair, a table, a sink, a tree, a person silhouette or an electrical symbol should not be implemented as a parametric Symbol unless there is a strong reason to do so. Those items are better handled as static `.opencad2d.json` files loaded through the Library browser.

## Why this separation matters

Keeping Symbols limited to truly parametric objects makes the application easier to maintain. It also keeps the Library flexible: new static objects can be added by placing files in the Library folder, without changing the application code.

For users, the difference is simple. Use Symbols when OpenCad2D must ask for dimensions or options and then generate geometry. Use Library when you want to insert an existing reusable drawing.

## Current scope

The current project decision is to keep only doors, windows and stairs as parametric objects. Stairs are the first implemented parametric object. The toolbar `Stair` button starts a default straight stair command with width 100, 18 treads, tread depth 28, riser height 17 and slab thickness 3. By default it inserts a plan stair, but before choosing the insertion point you can use the HUD options `Plan`, `Side` or `Front` to choose the generated representation. After insertion, select the stair and use the Property Panel to change view, width, tread count, tread depth, riser height, insertion point and structure options. In plan view, the stair also has a conventional direction arrow along its axis. The `Plan arrow` property can show it from first tread to last tread, reverse it from last to first, or hide it. The optional `Plan section marker` property draws the classic pair of 30-degree section/break lines near the middle of the stair, spaced by the slab thickness.

The command aliases are `STAIR`, `STAIRS`, `SCALA` and `ST`. The command expects a point or a view option, so the Dynamic HUD exposes X/Y fields when editing is activated with TAB and also shows the `Plan`/`Side`/`Front` options while the insertion point is pending.
