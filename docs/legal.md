## DXF interoperability

OpenCad2D implements a focused subset of ASCII DXF import/export behavior for interoperability.

The project documentation should describe OpenCad2D behavior in original words and should not copy large portions of third-party DXF documentation.

## Patent note

This project implements common 2D CAD concepts such as entities, layers, snapping, selection, transformations, measurements and import/export helpers.

No patent clearance is implied by this document. A formal patent review requires professional legal analysis.
