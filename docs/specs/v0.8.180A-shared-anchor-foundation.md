# v0.8.180A — Shared Anchor Foundation

## Purpose

This slice starts the parametric doors/windows track without implementing doors or windows yet. It converts the planning contract in `docs/specs/shared-anchor-system.md` into a small reusable core model that future tools can depend on.

The goal is to avoid each future parametric or annotation feature inventing its own insertion convention. Doors, windows, annotation callouts and future dynamic symbol tools should all use the same 9-point vocabulary and the same CAD-coordinate placement rules. Native block insertion is explicitly excluded: blocks keep the base point chosen when the block is created.

## Scope

Implemented in this slice:

- `AnchorPoint`, the canonical 9-value enum;
- `AnchorPointDescriptor`, the UI/grid metadata for every anchor;
- `AnchorPlacement`, the resolved placement result for a local bounding box, selected anchor and target insertion point;
- `AnchorPointService`, the shared resolver for descriptor order, grid mapping, keypad shortcut mapping, parsing/recovery and placement translation;
- automated tests for descriptor order, CAD-coordinate resolution, 3x3 selector mapping, keypad mapping, translation and invalid persisted value recovery.

This slice intentionally does not add a visible HUD selector, Property Panel editor, `DoorEntity` or `WindowEntity`. Those belong to later v0.8.180 slices.

## Canonical values

The canonical values are:

```text
TopLeft       TopCenter       TopRight
MiddleLeft    Center          MiddleRight
BottomLeft    BottomCenter    BottomRight
```

They are stored as stable names, not ordinal values. Persistence code for future entities must write strings such as `"Center"` and must recover invalid or missing values using the feature default.

## Coordinate contract

The service treats the input bounding box as CAD geometry, not screen geometry.

- `Top*` anchors use `MaxY`.
- `Bottom*` anchors use `MinY`.
- `Left` anchors use `MinX`.
- `Right` anchors use `MaxX`.
- center anchors use the midpoint of the relevant axis.

Any screen-space inversion belongs only in rendering or UI controls. Model, persistence and command placement must remain CAD-oriented.

## UI mapping contract

The descriptors expose `Row`, `Column` and numeric shortcut metadata for the future HUD selector. Rows and columns are UI-grid positions, with row `0` at the top and column `0` at the left.

The numeric mapping follows the keypad layout:

```text
7 TopLeft       8 TopCenter       9 TopRight
4 MiddleLeft    5 Center          6 MiddleRight
1 BottomLeft    2 BottomCenter    3 BottomRight
```

This mapping is now a core contract. The future HUD selector should call the shared service rather than duplicating the mapping.

## Placement contract

For a local bounding box, selected anchor and target point, placement is resolved as:

```text
local anchor point = point of the selected anchor inside the local bounds
translation        = target point - local anchor point
```

The translation can then be applied by the future tool according to its own transform model. For example:

- door/window tools may use it to position the parametric local footprint around a picked wall point;
- coordinate callouts may use it to attach the visible marker without moving the measured target point.

## Out of scope

The following are intentionally deferred:

- visible HUD 3x3 selector; implemented later by v0.8.180B;
- Property Panel anchor editor;
- JSON persistence on any existing entity;
- changing current block insertion behavior;
- changing current Library insertion behavior;
- replacing block base-point insertion with a bounding-box anchor;
- changing image or stair behavior;
- door/window geometry, wall masking and export.

## Tests

Automated tests are in `AnchorPointServiceTests`.

Minimum test coverage for this slice:

- descriptor order is top-left to bottom-right;
- every anchor resolves against a CAD-oriented `BoundingBox2D`;
- every 3x3 grid position maps to the expected anchor;
- keypad shortcuts map to the expected anchor;
- placement translation moves the selected local anchor to the requested target;
- invalid persisted values recover to the requested default.
