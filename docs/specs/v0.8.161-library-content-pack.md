# v0.8.161 — First Library content pack

Status: [~] implemented in the repository, pending maintainer-side manual validation.

This milestone gives the already implemented Library Browser a first real content set. The goal is deliberately modest: a small curated pack that proves the browser, preview, publish copy, insertion, block-reference reuse and explode workflows with realistic static objects.

## Implemented pack

The first pack lives under the repository-level `library/` folder. The application project already includes this folder as publish content through `src/OpenCad2D.App/OpenCad2D.App.csproj`.

```text
library/
  README.md
  arredo/
    divano_3_sopra.opencad2d.json
    sedia_sopra.opencad2d.json
    tavolo_4_sopra.opencad2d.json
  cucina/
    fornello_sopra.opencad2d.json
    frigo_sopra.opencad2d.json
    lavandino_sopra.opencad2d.json
  sanitari/
    bidet_sopra.opencad2d.json

  simboli/
    nord_semplice.opencad2d.json
    scala_grafica_100.opencad2d.json
```

These files are ordinary native OpenCad2D drawings. They intentionally avoid nested block references because the first Library insertion pass rejects library items containing block references.

## Design rules

The first pack follows a few strict rules so it remains useful as a stable baseline:

- each item is a standalone `.opencad2d.json` v1 document;
- every insertable entity is on layer `0`;
- the pack uses simple first-pass entities only: lines, polylines, circles, ellipses and basic text where needed;
- furniture, kitchen objects and sanitary fixtures use the object center as `(0,0)`;
- symbols use their natural insertion reference as `(0,0)`;
- doors and windows are not provided as static library files, because they are planned as parametric objects;
- stairs are not provided as static library files, because `StairEntity` already exists.

## Validation expected before marking complete

This milestone can be marked `[x]` after the maintainer verifies the following on Windows:

```text
make check or dotnet test
publish output contains library/**
Library Browser shows 4 categories: arredo, cucina, sanitari, simboli
Each item has a visible preview
Each item can be inserted from the Library Browser
Repeated insertion reuses the same block definition
Undo removes an inserted item cleanly
Explode converts the inserted block reference into ordinary entities
Save/reopen preserves inserted Library items
SVG/PDF/DXF smoke export does not crash with inserted items
```

## Future expansion

Do not grow the Library into hundreds of files immediately. The next expansion should happen after v0.8.162 compatibility testing and should add coherent groups in small batches: bedroom, office, people, vehicles, garden/outdoor, electrical and plumbing. Each batch should keep top/front/side variants explicit in file names.
