# v0.8.180E — Minimal WindowEntity

This slice adds the first persistent parametric architectural window entity. It deliberately follows the same narrow implementation style used for the first door slices: introduce the stable model, generated plan linework, command insertion, HUD anchor opt-in, persistence and vector export, without trying to solve advanced wall editing yet.

## Scope

`WindowEntity` is a real CAD entity, not a static Library block. It stores its insertion point, width, wall thickness, frame offset, 9-point anchor, local axes and non-destructive wall-mask preference. Generated geometry is rebuilt from those parameters whenever the entity is rendered, exported or measured for interaction.

The first window symbol is intentionally schematic and plan-oriented. It draws the opening edges, jambs, two internal frame/glass lines and a center divider line. This is enough to make the entity recognizable in architectural plan drawings while keeping the model small and testable.

## Placement and anchor behavior

Windows use the shared 9-point anchor selector introduced by v0.8.180A/v0.8.180B. The anchor is resolved against the opening rectangle, not against decorative linework. The default remains `MiddleLeft`, matching the door default and making insertion predictable when placing the object on a wall centerline or opening edge.

Block references and static Library items still do not use this anchor selector. Their insertion point remains the base point chosen when the block/item was created.

## Wall mask behavior

The window supports the same non-destructive wall-opening mask contract as doors. When `MaskWallOpening` is enabled, a wipeout-style polygon is generated over the opening rectangle and drawn/exported before the visible window linework. It hides wall lines visually but never trims, splits or edits the underlying wall geometry.

This is the required first implementation. Real wall trimming remains a later optional command.

## Command behavior

The command is `WINDOW`, with aliases `FINESTRA` and `WN`. It accepts a point or the options:

- `A = Anchor`, which tells the user to use the HUD 3x3 selector or numeric shortcuts 1-9;
- `M = Mask`, which toggles the default wall mask state for subsequently inserted windows.

The tool exposes preview geometry while the pointer moves. The document is modified only on commit, through a normal undoable add-entity command.

## Out of scope

This slice does not add editable HUD fields for width, wall thickness or frame offset. It does not add window styles, double/triple windows, sill graphics, swing casements, real wall trimming, automatic wall detection or snap-to-wall alignment. Those features can be added incrementally after the minimal door/window pair is stable.
