# Specification — v0.8.120 Symbols and Parametric Drafting Helpers

## Purpose

Add practical drafting helpers for architectural and technical drawings while separating fixed reusable content from parametric generators.

Fixed reusable content should move to the Library workflow as `.opencad2d.json` snippets. Direct symbol tools should be reserved for objects that need parameters, such as doors, windows, stairs, section/elevation markers with configurable labels, or title blocks.

## Design principle

Parametric drafting tools should generate ordinary OpenCad2D geometry or block definitions/references.

Preferred output:

```text
Tool parameters -> generated lines/arcs/text/polylines -> optional block definition/reference
```

Avoid special entity types unless the symbol needs persistent parametric editing after insertion.

## Implemented first-pass tools

### North Symbol

Status: first pass implemented.

Purpose: insert a simple north arrow.

Current v0.8.120 behavior:

- command/tool: `NorthSymbol`;
- aliases: `NORTH`, `NORTHSYMBOL`, `NS`;
- toolbar button: `North Symbol` under `SYMBOLS`;
- user picks one insertion point;
- active object snaps are honored for the picked insertion point;
- default size: 50 model units;
- output is ordinary geometry: one vertical line, two arrow-side lines, one circle and one `TextEntity` with label `N`;
- generated geometry uses the current layer and current text format;
- insertion is one undoable composite command.

Planned later parameters:

- configurable size;
- rotation;
- style: simple arrow / circle arrow.

Default behavior:

- label `N`;
- insertion point `(0,0)` is the symbol base point;
- rotation 0 means north points up in world coordinates;
- the `N` label is placed beside/above the arrow tip, not over the arrow shaft.

### Metric Scale Bar

Status: first pass implemented.

Purpose: insert a graphic scale bar for printed drawings.

Current v0.8.121 behavior:

- command/tool: `ScaleBar`;
- aliases: `SCALEBAR`, `SBAR`, `GRAPHICSCALE`;
- toolbar button: `Scale Bar` under `SYMBOLS`;
- user picks one insertion point;
- active object snaps are honored for the picked insertion point;
- output is ordinary geometry: one horizontal baseline, six vertical tick lines and seven text labels;
- default represented distance is `0` to `5 m`, with major divisions every `1 m`;
- default label scale text is `1:100`;
- generated geometry uses the current layer and current text format;
- insertion is one undoable composite command.

Planned later parameters:

- drawing scale: 1:20, 1:50, 1:100, 1:200, custom;
- represented real length;
- number of major divisions;
- optional minor divisions;
- text height;
- optional filled/alternating segments when hatch/fill support is available.

Important rule:

The tool must make clear whether values are paper units or model units. The first version assumes model-space drawing and generates fixed geometry whose labels communicate the represented real-world distance.

### Section Symbol

Status: planned as a parametric helper, not as a fixed library-only item.

Purpose: insert a section line marker, such as `A-A`.

Parameters:

- start point;
- end point;
- label;
- arrow size;
- text height;
- flip arrows optional.

Output:

- line;
- arrowheads;
- text labels.

### Elevation Symbol

Status: planned as a parametric helper, not as a fixed library-only item.

Purpose: insert an elevation/prospect marker.

Parameters:

- insertion point;
- direction angle;
- label;
- sheet/reference text optional;
- size.

Output:

- circle/triangle/arrow lines;
- text.

### Title Block / Testalino

Status: planned as a parametric helper.

Purpose: generate a simple sheet title block.

Parameters:

- paper size: A4/A3/A2/A1;
- orientation: portrait/landscape;
- margins;
- title;
- drawing number;
- scale;
- date;
- author;
- revision;
- company/project fields optional.

Output:

- lines/polylines;
- text/MTEXT;
- optional block definition/reference.

First version can generate a simple fixed layout rather than a fully editable table system.

## UI strategy

Updated strategy:

- Avoid adding many fixed-symbol buttons under `SYMBOLS`.
- Add a dedicated `Library` button/window for fixed reusable content stored as `.opencad2d.json` files.
- Keep direct `Symbols`/tool buttons for parametric objects that need a dialog or command prompts before generation.
- Use one small dialog per parametric tool where parameters are needed.
- Use command-line defaults where simple.
- Insert generated output by point on canvas.

This keeps the toolbar compact and makes the symbol set extensible without recompiling the application for every new fixed object.

See `docs/specs/v0.8.122-library-browser.md` for the Library Browser design.

## Layer policy

Preferred behavior:

- Use current layer for generated geometry.
- Optionally create/reuse an `Annotations` layer for text-heavy symbols if user preference exists.

Do not silently create many specialized layers in v1.

## Testing checklist

Core tests:

- generated north symbol has expected bounding size;
- north symbol insertion creates ordinary undoable geometry;
- north symbol insertion honors endpoint snap;
- metric scale bar creates baseline, six ticks and labels `0` through `5 m` plus `1:100`;
- section symbol creates two arrowheads and label text;
- elevation symbol rotates correctly;
- title block creates expected outer frame size.

Interaction tests:

- each symbol inserts at picked point;
- undo removes all generated entities as one operation;
- generated block reference, if used, can be moved/rotated/scaled.

Manual tests:

- create a small architectural sheet with north symbol, scale bar, title block, section and elevation markers;
- save/reopen;
- export to SVG/PDF/DXF where supported.

## Accepted first-version limitations

- No dynamic symbol editing dialog after insertion unless easy through Property Panel.
- The large fixed-symbol collection is handled by the Library Browser milestone instead of this parametric-tools spec.
- No automatic sheet layout system.
- No automatic scale synchronization with viewport/paper space because paper space is not yet implemented.


## Metric Scale Bar geometry update

`ScaleBarTool` now generates the requested 0–1000 metric scale bar using `(0,0)` as the local insertion origin.

Generated ordinary entities:

- 6 closed polylines for alternating filled/empty scale rectangles.
- 7 vertical tick lines at `0`, `100`, `200`, `300`, `400`, `500`, `1000`.
- 7 text labels at `y = -50`: `0`, `100`, `200`, `300`, `400`, `500`, `1000`.

The selected insertion point is added as an offset to every local coordinate.


## Decision — Library versus Symbols

From the next steps onward, fixed reusable content should not be added as individual toolbar buttons. Examples: furniture, common annotation symbols, sanitary fixtures, north-arrow variants, graphic-scale variants and standard detail symbols.

These belong in the external Library workflow as `.opencad2d.json` files.

The direct symbol/tool area should stay focused on parametric generators. Examples: doors, windows, stairs, section markers, elevation markers and title blocks where dimensions, labels, orientation or style choices are requested before drawing.
