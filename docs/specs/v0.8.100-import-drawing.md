# Specification — v0.8.100 Import Drawing

## Purpose

Allow the user to import another `.opencad2d.json` drawing into the current document without replacing the current document.

This is the first reuse-oriented milestone before blocks and symbol libraries.

## User story

As a user, I want to insert an existing OpenCad2D drawing into my current drawing so that I can reuse details, symbols, sheet layouts or partial drawings without manually recreating them.

## Command

Suggested command name:

```text
IMPORTDRAWING
```

Suggested aliases:

```text
IMPORT
IMPDWG
```

Toolbar label:

```text
Import Drawing
```

## Initial workflow

v1 workflow:

1. User clicks `Import Drawing` or types command.
2. Application opens a file picker for `.opencad2d.json`.
3. Application loads the selected document.
4. Application inserts its entities into the current document at world origin.
5. Application merges dependent resources.
6. Application reports imported entity count and skipped/failed references if any.

Deferred workflow:

- Pick insertion point.
- Pick or type scale.
- Pick or type rotation.
- Preview imported drawing before commit.

## Resource merge rules

### Entity IDs

All imported entities must receive new IDs.

No imported entity may keep an ID that already exists in the current document.

### Layers

Layer merge policy:

1. If an imported layer ID does not exist, add it.
2. If an imported layer ID exists and is equivalent, reuse it.
3. If an imported layer ID exists but differs materially, create a conflict-safe ID.

Suggested conflict ID format:

```text
Imported_<OriginalLayerId>
Imported_<OriginalLayerId>_2
```

Material layer differences include at least:

- name/id;
- visibility;
- locked state;
- line format;
- fill color.

### Line formats

Line format merge policy:

1. If imported format ID does not exist, add it.
2. If imported format ID exists and is equivalent, reuse it.
3. If imported format ID exists but differs, create a conflict-safe ID and remap imported entities/layers.

Equivalence should compare:

- color;
- lineweight;
- style;
- dash pattern values.

### Text formats and dimension styles

Use the same policy as line formats:

- reuse equivalent IDs;
- create conflict-safe IDs for non-equivalent conflicts;
- remap imported entities accordingly.

### External image references

Imported image paths must be handled carefully.

Rules:

1. If the imported JSON contains a relative image path, resolve it against the imported document folder.
2. If the imported JSON contains an absolute image path, keep it as an absolute resolved source path.
3. After import, store paths according to the current document persistence policy.
4. If the current document is saved, prefer relative paths to the current document folder when possible.
5. If the image file is missing, still import the image reference entity as a missing reference placeholder.

## Undo/redo

The import operation must be undoable as one operation.

Undo should remove:

- all imported entities;
- resources added only for the import if they are not used elsewhere, if resource cleanup exists;
- otherwise unused imported resources may remain as an accepted first-version limitation.

Redo should restore the imported batch.

## Selection after import

Recommended behavior:

- Select all imported entities after import.
- Set status message to report the import result.

This makes it easy to move the imported drawing immediately even before insertion-point workflow exists.

## Error handling

The command must fail cleanly when:

- the selected file is not valid JSON;
- the selected file is not a valid OpenCad2D document;
- the selected file cannot be read;
- the current document cannot accept a resource merge.

The current drawing must remain unchanged on failure.

## Testing checklist

Core/persistence tests:

- import simple drawing with one line;
- import drawing with layer not present in current document;
- import drawing with equivalent existing layer;
- import drawing with conflicting layer ID;
- import drawing with equivalent/conflicting line format;
- import drawing with text format/dimension style dependencies;
- imported entity IDs are regenerated;
- imported image relative paths are resolved against source document folder;
- missing imported image remains a missing reference but does not abort import;
- import is undoable as one operation.

Manual tests:

- import a simple file into an empty document;
- import a file into a non-empty document;
- import a file with external images;
- save/reopen after import;
- export imported geometry to SVG/PDF/DXF where supported.

## Accepted first-version limitations

- Import at origin only.
- No preview.
- No insertion scale/rotation.
- No resource cleanup after undo if resource cleanup is not already available.
- Imported block definitions are not relevant until blocks exist.
